# dsh-app-row-brand

把你的图片和文字放进 DeepSeek Harness **桌面端窗口标题栏**——就是收起侧边栏、原生「应用 / 编辑」菜单、最小化 / 最大化 / 关闭按钮所在的那一条 40px 横栏。内容在「设置 → 标题栏」里编辑。

## 功能

- 向框架级 `shell.overlay` 槽位注册一个条目，把一条横栏固定在视口顶部，正好落在 shell 为 `[data-windows-titlebar]` 绘制的那条标题栏里。不替换任何列内容，侧栏自带的品牌行保持原样。
- 最多 12 个条目。多于一个时自动轮播：每个条目有自己的显示时长（秒，存储为 `durationMs`）。
- 开箱默认两条内容每 30 秒轮播：「请到设置界面设置语句」与「DeepSeek Harness」，都带从左到右流光、跟随界面默认字体；「设置 → 标题栏 → 恢复默认设置」可还原。
- 每个条目独立携带：文字、文字颜色、字体、字号、加粗、下划线、图片、图片宽度、对齐方式、可选流光。
- 字体从本机读取：优先使用 Local Font Access API；不可用时用 canvas 度量逐个探测候选字体，所以设置里的字体列表是这台机器真正装了的。
- 流光沿用状态挂件的做法：文字用渐变填充并裁到字形上，高光按一块循环平移扫过；周期（秒）、高光颜色、扫描方向（默认从左到右，可选从右到左）都按条目独立设置。
- 可以手动切换当前显示的条目并「固定」：固定后停在当前条目、停止自动轮播，再次取消固定才恢复。
- 任意条目可以标记为**暂不展示**：轮播、上一个/下一个都会跳过它，条目下拉里会带「暂不展示」标记；取消后立刻回到轮播（之前对它的固定也会恢复生效）。
- 图片高度锁定为标题栏高度（40px），只有宽度可调（8–240px）。
- 上传的图片会按栏高缩放后以 data URL 存进 `localStorage`；也可以直接填图片链接。
- 在非 Windows 桌面端环境下横栏不渲染，普通网页不受影响。

## 安装

从 npm 安装：

```shell
dsh plugin --profile <profile> add dsh-app-row-brand
```

从本地目录安装：

```shell
dsh plugin --profile <profile> add <本目录路径>
```

DSH 桌面端请用插件管理器而不是命令行，并且安装后**完整退出再打开**一次，让渲染层加载新的客户端模块。之后对链接目录的修改会热重载。

打开 **设置 → 标题栏** 开始编辑。

## 设置项

| 项 | 作用 |
|---|---|
| 条目 | 选择条目，新增或删除 |
| 顺序 | 上移 / 下移，轮播顺序跟着变 |
| 显示状态 | 暂不展示；轮播与上一个/下一个会跳过 |
| 显示控制 | 上一个 / 固定（可切换）/ 下一个，以及当前「正在显示第 N/M 条」状态 |
| 文字 | 条目文字，最多 60 字 |
| 颜色 | 取色器 + R/G/B 输入 |
| 字体 / 字号 | 本机字体（可切「自定义…」手填）；9–40px |
| 加粗 / 下划线 | 字重 700 与下划线 |
| 图片 / 宽度 | 上传、填链接或清除；宽度 8–240px |
| 对齐方式 | 居中 / 靠右 / 靠左 |
| 流光 | 开关、周期（秒）、扫描方向、高光颜色 |
| 显示时长 | 该条目停留多久（秒）后切下一条 |

## 实现结构

| 文件 | 作用 |
|---|---|
| `cordis.patch.yml` | profile 层：插入 `dsh-app-row-brand` 这一行 |
| `index.js` | Host 半部：空的 `apply()` |
| `client.js` | 浏览器半部：标题栏横栏、轮播与设置页 |
| `locale/*.json` | 插件页的标题与描述 |

`package.json` 声明了 `dsh.bundle.patch`（使这个包成为 profile 层）以及 `dsh.client` 的 `inject`，其中列出浏览器半部要扩展的两个槽位宿主：`@deepseek-ai/dsh-client-ui-layout`（框架 + `shell.overlay`）和 `@deepseek-ai/dsh-client-ui-settings`。

## 限制

- 所有配置按浏览器配置存在 `localStorage` 里，不写进 profile 的插件配置。
- 上传的图片会重新编码为 4× 栏高的 PNG；过大的图片可能超出本机存储预算而被拒绝。
- 横栏本身是窗口拖动区域，不拦截鼠标输入。
- 只有横栏挂载时（桌面窗口存在时）轮播才会推进。
